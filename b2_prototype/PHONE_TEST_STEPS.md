# B2 — 手機／多瀏覽器實機測試步驟（需擁有者協助）

容器只有 Chromium，**手機 Safari／Android Chrome 與桌面 Firefox 無法在這裡測**。這份是給你在真實裝置上手動跑的檢查清單。這是**隔離試作頁**的測試，**不碰正式資料、不收款**。

## 最簡單的做法：用手機打開一個網址（已上線）
在每一台要測的手機／電腦上，用該裝置的瀏覽器打開：

**`https://balance-diet.chair22752033.workers.dev/ui-assets/selftest/`**

這頁會自動跑 6 項加密相容性檢查，**不需要登入、不會上傳任何資料、不會存你的內容**。
看到綠色「✓ 這台裝置完全支援（6/6）」就代表這台瀏覽器 OK。
看到紅色（任何一項 ✗），**把整頁截圖給我**（截圖最下方有裝置資訊）。

## 要測的裝置（至少這三種）
- iPhone / iPad 的 **Safari**
- Android 的 **Chrome**
- 桌面 **Firefox**

## 六項檢查代表什麼
1. Web Crypto 存在
2. AES-KW 產生非匯出金鑰
3. HKDF-SHA256 導出金鑰
4. AES-GCM 加解密來回
5. 不可匯出金鑰無法被匯出
6. IndexedDB 可存取金鑰

這六項是未來「使用者持鑰加密」的前提。只要有一台常見手機某項 ✗，我就會改用等效做法並重測。
